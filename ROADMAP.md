# DSA Study Roadmap — FAANG / High-Paying SWE

The plan this repo's programs were written against. Code for a topic is added
only once it is implemented and tested; see the README for what currently
exists.

## Phase 1: Foundations (Weeks 1-2)

| Topic | Goal | Problems |
|-------|------|----------|
| Arrays & Hashing | Master two-pointer, sliding window, prefix sum | 15 |
| Strings | Palindrome, anagram, pattern matching | 8 |
| Recursion | Think recursively, backtracking basics | 5 |

## Phase 2: Core Data Structures (Weeks 3-4)

| Topic | Goal | Problems |
|-------|------|----------|
| Linked Lists | Reverse, merge, cycle detection, fast/slow | 8 |
| Stacks & Queues | Monotonic stack, parentheses, queue using stacks | 8 |
| Trees (Binary, BST) | Traversals, DFS/BFS, LCA, serialize | 12 |

## Phase 3: Advanced (Weeks 5-6)

| Topic | Goal | Problems |
|-------|------|----------|
| Heaps / Priority Queue | Top K, median finding | 6 |
| Graphs | Adj list, DFS/BFS, topological sort, connected components | 10 |
| Dynamic Programming | 1D DP, 2D DP, knapsack, LCS, LIS | 15 |

## Phase 4: System Design (Week 7+)

- Read **Designing Data-Intensive Applications** (ch 1-6, 9, 11)
- Read **Alex Xu's System Design Interview** (vol 1)
- Practice: design URL shortener, chat system, rate limiter, news feed
- Do 2-3 mock interviews

## Phase 5: Behavioral (Ongoing)

Prepare 5-7 STAR stories:

- Conflict with a teammate
- Technical challenge solved
- Design/architecture decision
- Mentored someone
- Took initiative
- Failed and learned
- Made something faster / cheaper
