# DSA Python — Beginner Programs

A collection of beginner-friendly Data Structures and Algorithms programs in Python. Each program is self-contained with examples.

## Topics

| Folder | Topics Covered |
|--------|---------------|
| `arrays/` | Reverse, rotate, two sum, merge, duplicates |
| `linked-lists/` | Singly linked list, reverse, detect cycle |
| `stacks-queues/` | Stack, queue, balanced parentheses |
| `recursion/` | Factorial, fibonacci, tower of hanoi |
| `sorting/` | Bubble, selection, insertion, merge, quick |
| `searching/` | Linear search, binary search |
| `strings/` | Palindrome, anagram, reverse, vowels |
| `hashing/` | Frequency count, two sum, first duplicate |

## How to Run

```bash
python arrays/reverse_array.py
```
